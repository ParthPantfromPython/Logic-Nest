# Logic Nest

A modern portfolio and coding-channel landing page for **Logic Nest**.

## Features
- Responsive single-page design
- Coding-focused hero section
- Learning tracks for Python, web development, and problem solving
- Featured project section
- Interactive copy button
- Mobile navigation
- No frameworks or build tools required

## Run locally
Open `index.html` in any modern browser.

## GitHub Pages
Enable **Settings → Pages → Deploy from a branch → main → / (root)** to publish the site with GitHub Pages.
