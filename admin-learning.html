Learning Manager Settings

Architecture and security notes for this workspace.
Public read model: only published courses and published, available lessons are exposed by RLS. Draft/admin data stays protected.

YouTube: playlist IDs are stored in Supabase. The API key belongs only in server-side Edge Function secrets.

Notes: files are stored in the private learning-notes bucket. Public course pages receive time-limited signed URLs only after the published-content check succeeds.

Automation: the repository includes a scheduled GitHub Actions sync workflow; it requires GitHub Secrets configured for the Supabase service-role REST access and YouTube API key.
